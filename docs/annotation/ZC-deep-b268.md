## 5. 七行门禁（`zc-commit.mjs` v12，`--rewrite-annot --base HEAD`）

首轮失败：`新增注释行 n=100 其中判据命中 1`。

```text
clipboard-image.ts:266  L  无信息列举
  spawn(file, args) 不经 shell，空格与引号原样传入。
```

原因是 L 判据**把代码片段里的 ASCII 逗号也当分隔符**：`(file, args)` 的 `,` 加上中文逗号共 2 个，
且行内没有谓词。改成「spawn 用参数数组调用且不经 shell，空格与引号原样传入。」后二轮通过。

这条也解释了为什么预检没拦住：预检用的同一套 `judgeEntries` 本应命中，是**首稿与预检稿不同**
（预检稿是「spawn 用参数数组形式，避免 shell 转义。」，落笔时改写过）。教训：
**预检必须跑最终正文**，不能在预检之后再润色。

已落成工具约束（不是纪律条文）：`_tools/precheck-assert.mjs`（blob `db7189f9b562`）。
`--record` 对当前 diff 的新增注释行跑 `judgeEntries` 并落快照（sha256 = 文件+行号+正文），
门禁前 `--verify` 重算并逐字比对，**记录后又改一个字即 `exit 7`**；命中非 0 时 `exit 1`。
负控：把 `clipboard-image.ts:266` 改回「都原样传入」→ `DRIFT #32` + `exit 7`。**b269 起首次使用**。
