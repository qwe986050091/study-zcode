## 3. 跟办 3：后期切批规则（>100 行文件）

写死如下，B9 起直接照用：

1. **切点优先级**：符号边界（顶层 `export` / `function` / `class` / `interface` 起始行）→ 逻辑段（一条完整注释块 + 其悬挂代码）→ 行数硬切。
2. **硬切约束**：只在空行或注释块边界落刀，禁止句中断行；硬切后仍 >100 行的，说明该文件需再拆一批，不得放宽行数上限。
3. **同文件只进出一次**：超限文件单独占一批（不与其他文件混批），批内按上述切点分 `Bx-1 / Bx-2` 多次门禁+提交，但中间不夹其他文件，整体登记为一个批次号。
4. **切点先定后改**：切点必须在改写前写入 TSV 的 batch 字段，不允许边改边切。
