196 条的类别构成（按键词启发式分类，优先级 条件 > 顺序 > 数据流，边界样本归入高优先级一类）：

| 类别 | 总体条数 | 占比 | 样本 n | 有+弱 | 仅「有」 |

- **按总体比例加权**：`有+弱` = 0.2555×1.00 + 0.1582×1.00 + 0.5867×0.818 ≈ **89.3%**；
  `仅「有」` = 0.2555×0.25 + 0.1582×0.80 + 0.5867×0.545 ≈ **51.0%**。
- 数据流被过采（样本 55% vs 总体 58.7% 接近，但条件/顺序各只 4–5 条，方差大），
  所以 **90.0% 只能读作「分层抽样率」，不能写成「写作质量九成合格」**；总体率的点估计用加权的 **89.3%**。

  这与「闸只保证不是无信息列举」一致，不代表每条都在补新约束。
